# Tech & Placement Quiz App 🚀

A native Android Quiz application built using **Kotlin** and **XML** in Android Studio.

## 🌟 Key Features
- **Curated Content:** Questions covering DSA, Quantitative Aptitude (SSC CGL/Placement level), Core CS, and 2026 Current Affairs.
- **Smart Logic:** Implemented dynamic deduplication using `SharedPreferences` and Kotlin Collections to prevent question repetition during sessions.
- **Monetization:** Integrated Start.io SDK for ads.
